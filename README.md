# Fisica UDA 2 - pacchetto per GitHub

Liceo Monti di Chieri, 2026-27, 3CSU e 3ESU, scienze umane, fisica.

## Che cosa caricare

Caricare **tutto il contenuto di questa cartella**, mantenendo le sottocartelle:

- `index.html`: UDA studenti / LIM, pagina iniziale.
- `immagini-libro/`: 34 immagini PNG originali, pagine 32-65, senza riduzione della definizione.
- `libro.html`: galleria del capitolo, con collegamenti a piena risoluzione.
- `guida-docente.html`: guida separata con soluzioni.
- `fonti/programma-fisica.pdf`: fonte curricolare richiamata nella guida.
- `.nojekyll`: file tecnico per la distribuzione statica.

Non caricare soltanto l’HTML e non usare il file ZIP come pagina del sito. Se usi lo ZIP, estrailo e carica i file e le sottocartelle contenuti. Il file iniziale si chiama `index.html` e deve trovarsi nella cartella pubblicata con GitHub Pages.

Gli HTML sono consultabili come sito tramite GitHub Pages; la normale vista dei file del repository mostra il codice HTML. La guida docente è separata dall’UDA, ma caricandola nello stesso sito sarà raggiungibile al suo indirizzo.

Tutti i collegamenti alle immagini del libro rimangono dentro questo pacchetto. Non sono necessari percorsi del PC o le altre cartelle del progetto. Il capitolo completo si consulta dalla galleria, senza scaricare un PDF aggiuntivo.

Le copie editoriali nel pacchetto sono state preparate su richiesta del docente; gli originali restano nell’archivio dei libri della 3CSU. Quando l’UDA viene modificata, aggiornare anche questa versione per GitHub prima di caricarla.

Verifica: 9 novembre 2026. Collegamenti locali e corrispondenza SHA-256 delle immagini verificati.
